def get_page_content(path):
    """Return raw file content for a given path."""
    with open(path, 'r', encoding='utf-8') as f:
        return f.read()

def find_by_id(content, elem_id):
    """Naive find: return the start tag containing id='elem_id' or None."""
    token = 'id="' + elem_id + '"'
    start = content.find(token)
    if start == -1:
        return None
    tag_start = content.rfind('<', 0, start)
    tag_end = content.find('>', start)
    if tag_start == -1 or tag_end == -1:
        return None
    return content[tag_start:tag_end+1]

def load_config():
    """Load config.json from repo root."""
    import json
    with open('config.json', 'r', encoding='utf-8') as f:
        return json.load(f)

How materials were constructed and why
- Goal: provide a small, deterministic pytest project where tests intentionally fail for realistic, common reasons after an app update.
- Files are minimal so a candidate can open, run, and edit quickly within 90 minutes.
- The test stack uses only Python standard library (no external dependencies) so the provided command (python -m pytest -q) runs in typical environments with pytest available.

Intended failing issues (one-to-one with core competencies to test)
1) Config/API change (tests expect config['base_url'] but config.json uses "app_url"):
   - Manifested in test_title: helpers.load_config() returns a dict without 'base_url' -> KeyError when accessing cfg['base_url'].
   - Candidate should update test to use cfg['app_url'] or modify the helper to normalize keys.

2) Selector/locator mismatch (element id changed):
   - test_login_button expects id 'login-btn' and uses a non-existent helper old_find_by_id; the current app uses id 'btn-login' and helpers.py exposes find_by_id.
   - Candidate should update test to use helpers.find_by_id and the correct id 'btn-login', or create a thin compatibility wrapper named old_find_by_id in helpers.py.

3) Timing/flakiness (hard sleep) and data path change:
   - test_users_data_loaded uses time.sleep(2) and reads data/users.json which no longer exists (file renamed to data/users_v2.json).
   - Candidate should replace the hard sleep with a deterministic check (e.g., read the correct file path directly or poll for the expected file) and fix the path to users_v2.json.

4) Deprecated helper usage:
   - tests call helpers.old_find_by_id which is intentionally absent to simulate a removed/deprecated helper API. Candidate must adapt tests to current helper API or add a compatibility function in tests/helpers.py.
