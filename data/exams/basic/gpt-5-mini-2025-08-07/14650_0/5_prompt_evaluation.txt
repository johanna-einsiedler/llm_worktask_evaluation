### Exam Purpose
Confirm that a candidate can maintain and update automated test scripts so they remain correct and useful when the system under test changes. Specifically, this exam verifies the candidate can:
- run an existing automated test suite,
- read and interpret test failures,
- update tests (selectors/expected values/waits/fixtures) to match the changed application behavior,
- keep tests readable and maintainable,
- re-run tests to demonstrate the fixes.

This is a practical, hands-on exercise that simulates the common, real-world activity of fixing and modernizing regression tests after a small change in the application.

---

### Core Competencies
The exam tests these concrete skills:
- Running automated tests and capturing test output.
- Diagnosing failing tests from stack traces and failure messages.
- Editing test code to reflect expected application changes (e.g., updated text, changed IDs/CSS classes, different JSON schema).
- Updating or adding test fixtures/data to reflect API/data model changes.
- Applying minimal, correct changes that fix tests without breaking intent (preserve test coverage).
- Writing concise rationale for each change.
- Demonstrating that all tests pass after updates.

Secondary competencies:
- Awareness of good test hygiene (clear assertions, stable selectors, minimal flakiness).
- Clear, structured reporting of changes.
