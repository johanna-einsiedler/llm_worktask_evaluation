# Basic Practical Exam: Program Compilation and Documentation

## Time Limit: 90 minutes

## Overview
You will work with a provided Python program that contains compilation errors. Your task is to fix these errors, compile the program successfully, and create comprehensive documentation following specific requirements.

## Materials Provided
You will receive:
- `buggy_program.py` - A Python file containing a simple inventory management system with intentional compilation errors
- `sample_data.txt` - Sample inventory data to test the program
- `documentation_template.md` - A template showing the required documentation structure
- `comment_guidelines.txt` - Specific commenting requirements and examples

## Tasks to Complete

### Task 1: Code Compilation (25 points)
1. Analyze the provided `buggy_program.py` file
2. Identify and fix ALL compilation errors to make the program run successfully
3. Test the program with the provided sample data to ensure it works correctly
4. Document each error you fixed using the exact format specified in the guidelines

### Task 2: Program Documentation (30 points)
Create comprehensive documentation that includes:
1. **Program Overview**: Write exactly 3-4 sentences describing what the program does
2. **Function Documentation**: For each function, provide:
   - Purpose (1 sentence)
   - Input parameters (name, type, description)
   - Return value (type and description)
   - Usage example
3. **Installation Instructions**: Step-by-step instructions (numbered list)
4. **User Guide**: How to run the program and interpret outputs

### Task 3: Code Commenting (25 points)
Add inline comments to the corrected code following these requirements:
1. Add a header comment block with program title, author (use "Exam Candidate"), and date
2. Add function-level docstrings for each function using the provided format
3. Add inline comments explaining complex logic (minimum 5 comments)
4. Add comments explaining any non-obvious variable names or calculations

### Task 4: Revision Documentation (20 points)
Document your changes using this exact format:
1. List each compilation error fixed with:
   - Line number where error occurred
   - Type of error (syntax, import, logic, etc.)
   - Exact change made
   - Reason for the change
2. List any improvements made beyond fixing errors
3. Provide a summary of testing performed

# Inventory Management System

import os
import sys
from datetime import datetime
import json

class InventoryManager:
    def __init__(self):
        self.inventory = {}
        self.transaction_log = []
    
    def load_inventory(self, filename):
        """Load inventory data from file"""
        try:
            with open(filename, 'r') as file:
                for line in file:
                    parts = line.strip().split(',')
                    if len(parts) == 4:
                        item_id = parts[0]
                        name = parts[1]
                        quantity = int(parts[2])
                        price = float(parts[3])
                        self.inventory[item_id] = {
                            'name': name,
                            'quantity': quantity,
                            'price': price
                        }
        except FileNotFoundError:
            print(f"Error: File {filename} not found")
            return False
        return True

    def add_item(self, item_id, name, quantity, price):
        """Add new item to inventory"""
        if item_id in self.inventory:
            self.inventory[item_id]['quantity'] += quantity
        else:
            self.inventory[item_id] = {
                'name': name,
                'quantity': quantity,
                'price': price
            }
        
        # Log the transaction
        self.transaction_log.append({
            'timestamp': datetime.now().isoformat(),
            'action': 'add',
            'item_id': item_id,
            'quantity': quantity
        })

    def remove_item(self, item_id, quantity):
        """Remove items from inventory"""
        if item_id not in self.inventory:
            print(f"Error: Item {item_id} not found in inventory")
        if self.inventory[item_id]['quantity'] < quantity:
            print(f"Error: Not enough {self.inventory[item_id]['name']} in stock")
        self.inventory[item_id]['quantity'] -= quantity

    def get_item_info(self, item_id):
        """Get information about specific item"""
            return self.inventory[item_id]
        return None

    def calculate_total_value(self):
        """Calculate total value of all inventory"""
        total = 0
        for item in self.inventory.values():
            total += item['quantity'] * item['price']
        return total

    def generate_report(self):
        """Generate inventory report"""
        print("\n=== INVENTORY REPORT ===")
        print(f"Generated on: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}")
        print("-" * 50)
        
        for item_id, item_data in self.inventory.items():
            print(f"ID: {item_id}")
            print(f"Name: {item_data['name']}")
            print(f"Quantity: {item_data['quantity']}")
            print(f"Price: ${item_data['price']:.2f}")

# Code Commenting Guidelines

## Header Comment Block Format:
"""
Program Title: [Title]
Author: Exam Candidate
Date: [Current Date]
Description: [Brief description]
"""

## Function Docstring Format:
def function_name(param1, param2):
    """
    Brief description of what the function does.
    
    Args:
        param1 (type): Description of parameter
        param2 (type): Description of parameter
    
    Returns:
        type: Description of return value
    
    Raises:
        ExceptionType: Description of when exception is raised
    """

## Inline Comment Requirements:
- Explain WHY code does something, not just WHAT it does
- Comment complex logic or calculations
- Explain non-obvious variable names
- Add comments before code blocks that perform specific tasks
- Minimum 5 inline comments required

## Examples of Good vs Bad Comments:

### Good Comments:
# Calculate tax based on regional rate (8.5% for this location)
tax_amount = subtotal * 0.085

# Retry connection up to 3 times before failing
for attempt in range(3):

### Bad Comments:
# Set x to 5
x = 5

# Loop through items
for item in items:
