    Here is brief explanation of the exam's purpose and structure intended for the evaluator: <examoverview> # Basic Practical Exam: Program Compilation and Documentation

## Exam Overview and Purpose

This practical exam assesses a candidate's ability to **compile code and create comprehensive documentation** for program development and revisions. Unlike theoretical assessments, this exam requires candidates to actually perform the complete workflow of code compilation, documentation creation, and code commenting that they would encounter in an entry-level programming position.

### Key Assessment Objectives:
- Compile code successfully while handling common compilation issues
- Write clear, structured documentation for program functionality
- Insert meaningful comments that enable code comprehension by others
- Document development revisions and changes systematically
- Demonstrate understanding of documentation standards and best practices

## Strategic Exam Structure

### Multi-Step Process Design
The exam follows a realistic development workflow:
1. **Code Analysis & Compilation** - Fix compilation errors in provided code
2. **Documentation Creation** - Write comprehensive program documentation
3. **Code Commenting** - Add meaningful inline comments
4. **Revision Documentation** - Document changes and improvements made

### Differentiation Strategy Elements

#### 1. **Real-World Complexity**
- Provide code with intentional compilation errors (missing imports, syntax issues)
- Include multiple functions with different purposes
- Require documentation of both user-facing and internal functionality

#### 2. **Decision Points That Reveal Competency**
- **Comment Placement**: Where and what type of comments to add
- **Documentation Depth**: What level of detail is appropriate for different audiences
- **Error Prioritization**: Which compilation errors to fix first
- **Revision Tracking**: How to document changes systematically

#### 3. **Multi-Audience Documentation**
- Technical documentation for other developers
- User documentation for end-users
- Inline comments for code maintainers

## Practical vs. Theoretical Assessment Features

### What Makes This Practical:
- **Actual Compilation**: Candidates must successfully compile working code
- **Real Documentation Creation**: Generate actual documentation files
- **Hands-on Problem Solving**: Fix real compilation errors
- **Code Modification**: Actually insert comments and make improvements

### Strategic Elements to Differentiate Candidates:

#### **Competent Candidates Will:**
- Systematically identify and fix compilation errors
- Write documentation that addresses multiple audiences appropriately
- Insert comments that explain *why* code works, not just *what* it does
- Create structured, searchable documentation
- Document revisions with clear rationale

#### **Less Competent Candidates Will:**
- Struggle with compilation error diagnosis
- Write documentation that only restates obvious code functionality
- Add superficial comments that don't aid understanding
- Create unstructured or incomplete documentation
- Fail to properly document their revision process

## Evaluation Framework

### Structured JSON Submission Format
The JSON format enables:
- **Objective Scoring**: Clear pass/fail criteria for compilation success
- **Standardized Evaluation**: Consistent documentation quality assessment
- **Automated Checking**: Verification of code compilation and basic functionality
- **Comprehensive Review**: All deliverables in one structured format

### Key Performance Indicators:
1. **Compilation Success Rate** (25%)
2. **Documentation Completeness** (30%)
3. **Comment Quality and Placement** (25%)
4. **Revision Documentation** (20%)

# Inventory Management System
# Contains intentional compilation errors for exam purposes
import os
import sys
from datetime import datetime
import json

class InventoryManager:
    def __init__(self):
        self.inventory = {}
        self.transaction_log = []
    
    def load_inventory(self, filename):
        """Load inventory data from file"""
        try:
            with open(filename, 'r') as file:
                for line in file:
                    parts = line.strip().split(',')
                    if len(parts) == 4:
                        item_id = parts[0]
                        name = parts[1]
                        quantity = int(parts[2])
                        price = float(parts[3])
                        self.inventory[item_id] = {
                            'name': name,
                            'quantity': quantity,
                            'price': price
                        }
        except FileNotFoundError:
            print(f"Error: File {filename} not found")
            return False
        return True

    def add_item(self, item_id, name, quantity, price):
        """Add new item to inventory"""
        if item_id in self.inventory:
            self.inventory[item_id]['quantity'] += quantity
        else:
            self.inventory[item_id] = {
                'name': name,
                'quantity': quantity,
                'price': price
            }
        
        # Log the transaction
        self.transaction_log.append({
            'timestamp': datetime.now().isoformat(),
            'action': 'add',
            'item_id': item_id,
            'quantity': quantity
        })

    def remove_item(self, item_id, quantity):
        """Remove items from inventory"""
        if item_id not in self.inventory:
            print(f"Error: Item {item_id} not found in inventory")
        if self.inventory[item_id]['quantity'] < quantity:
            print(f"Error: Not enough {self.inventory[item_id]['name']} in stock")
        self.inventory[item_id]['quantity'] -= quantity
            'action': 'remove',

    def get_item_info(self, item_id):
        """Get information about specific item"""
            return self.inventory[item_id]
        return None

    def calculate_total_value(self):
        """Calculate total value of all inventory"""
        total = 0
        for item in self.inventory.values():
            total += item['quantity'] * item['price']
        return total

    def generate_report(self):
        """Generate inventory report"""
        print("\n=== INVENTORY REPORT ===")
        print(f"Generated on: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}")
        print("-" * 50)
        
        for item_id, item_data in self.inventory.items():
            print(f"ID: {item_id}")
            print(f"Name: {item_data['name']}")
            print(f"Quantity: {item_data['quantity']}")
            print(f"Price: ${item_data['price']:.2f}")
            print(f"Total Value: ${item_data['quantity'] * item_data['price']:.2f}")
            print("-" * 30)
        
        print(f"TOTAL INVENTORY VALUE: ${self.calculate_total_value():.2f}")

def main():
    # Create inventory manager instance
    manager = InventoryManager()
    
    # Load sample data
    if manager.load_inventory('sample_data.txt'):
        print("Inventory loaded successfully!")
    else:
        print("Failed to load inventory data")
        return
    
    # Test adding items
    manager.add_item('ITEM005', 'Wireless Mouse', 15, 29.99)
    manager.add_item('ITEM001', 'Laptop Computer', 5, 899.99)  # Add to existing
    
    # Test removing items
    manager.remove_item('ITEM002', 3)
    
    # Test item lookup
    item_info = manager.get_item_info('ITEM003')
    if item_info:
        print(f"Found item: {item_info['name']} - Quantity: {item_info['quantity']}")
    
    # Generate final report
    manager.generate_report()

if __name__ == "__main__":
    main()
