## Explanation of Correct Answers and Derivation

### Bug Identification and Fixes

**BUG001 - Missing Data Persistence (Critical)**
- **Location**: `update_stock()` method, line after `self.products[product_id]['quantity'] = new_qty`
- **Issue**: Stock updates are made in memory but never saved to CSV file
- **Evidence**: Code comment states "BUG: Missing call to save_products() - changes not persisted to file"
- **Correct Fix**: Add `self.save_products()` call at the end of the `update_stock()` method
- **Verification**: Update stock, restart program, verify changes persist

**BUG002 - Missing User Interface Pause (Critical)**
- **Location**: `run()` method main loop, after each menu operation
- **Issue**: Menu immediately redisplays without allowing user to read operation results
- **Evidence**: Code comment states "BUG: Missing pause for user to read results before showing menu again"
- **Correct Fix**: Add `input("\nPress Enter to continue...")` after each menu operation
- **Verification**: Run any menu option, confirm system waits for user input

### Performance Optimization

**PERF001 - Unnecessary Loop (Critical)**
- **Location**: `generate_sales_report()` method, lines with `for _ in range(100):`
- **Issue**: Redundant 100-iteration loop makes calculations 100x slower and requires compensation division
- **Evidence**: Code comments mark "PERFORMANCE BUG: This unnecessary loop makes the report 100x slower"
- **Correct Fix**: 
  - Remove the `for _ in range(100):` loop
  - Remove all division by 100 operations that compensate for the loop
  - Keep single iteration through products
- **Expected Result**: Report completes in <1 second instead of 10+ seconds

### Feature Enhancement - Low Stock Alert

**Implementation Requirements**:
- **Threshold**: Products with quantity < 10 units
- **Display Format**: Product ID, Name, Current Quantity, Recommended Reorder Quantity
- **Reorder Formula**: current_quantity + 50
- **File Output**: Save to "low_stock_alerts.txt" in CSV format
- **Menu Integration**: Add as option "5"

**Expected Low Stock Items from Sample Data**:
- P002: Organic Cotton T-Shirt (8 units) → Reorder: 58
- P006: Coffee Mug Set (6 units) → Reorder: 56  
- P009: Backpack (9 units) → Reorder: 59
- P012: Face Moisturizer (7 units) → Reorder: 57

**Correct Implementation Structure**:
```python
def low_stock_alert(self):
    low_stock_products = []
    
    # Find products below threshold
    for product_id, details in self.products.items():
        if details['quantity'] < 10:
            reorder_qty = details['quantity'] + 50
            low_stock_products.append({
                'id': product_id,
                'name': details['name'],
                'current_qty': details['quantity'],
                'reorder_qty': reorder_qty
            })
    
    # Display results
    if low_stock_products:
        print("\n=== LOW STOCK ALERTS ===")
        for item in low_stock_products:
            print(f"Product ID: {item['id']}")
            print(f"Name: {item['name']}")
            print(f"Current Quantity: {item['current_qty']}")
            print(f"Recommended Reorder Quantity: {item['reorder_qty']}")
        
        # Save to file
        with open('low_stock_alerts.txt', 'w') as file:
            for item in low_stock_products:
                file.write(f"{item['id']},{item['name']},{item['current_qty']},{item['reorder_qty']}\n")
    else:
        print("No low stock items found.")
```
