## Explanation of Correct Answers and Derivation

### Analysis Phase - Bug Identification

**BUG001 - Missing Data Persistence (Critical)**
- **Location**: `update_stock()` method, after line `self.products[product_id]['quantity'] = new_qty`
- **Issue**: Changes to product quantities are made in memory but never saved to the CSV file
- **Detection Method**: Test stock update, restart program, verify changes are lost
- **Evidence**: Comment in code states "BUG: Missing call to save_products() - changes not persisted"
- **Impact**: Critical - all stock updates are temporary and lost on program restart

**BUG002 - User Experience Issue (Critical)**
- **Location**: `run()` method main loop, after each menu operation
- **Issue**: No pause after operations, menu immediately redisplays without user seeing results
- **Detection Method**: Run any menu option, observe results disappear immediately
- **Evidence**: Comment in code states "BUG: Missing input() pause - menu immediately redisplays without user seeing results"
- **Impact**: Critical - users cannot read operation results

**PERF001 - Performance Bottleneck (Critical)**
- **Location**: `generate_sales_report()` method, lines with `for _ in range(100):`
- **Issue**: Unnecessary 100-iteration loop multiplies all calculations by 100, then attempts to correct with division
- **Detection Method**: Sales report takes excessive time and shows incorrect fractional values
- **Evidence**: Comments in code identify "PERFORMANCE BUG" and "BUG: Division by 100 to compensate"
- **Impact**: Critical - makes feature unusable and produces wrong results

### Bug Fixes - Implementation Solutions

**Fix for BUG001**: Add persistence call
```python
self.products[product_id]['quantity'] = new_qty
print(f"Stock updated successfully. New quantity: {new_qty}")
self.save_products()  # Add this line
```

**Fix for BUG002**: Add user pause
```python
elif choice == '1':
```

**Fix for PERF001**: Remove redundant loop and divisions

### Feature Enhancement - Low Stock Alert Implementation

**Required Implementation**:
```python
def low_stock_alert(self):
    """Check and display low stock alerts"""
    low_stock_products = []
    
    for product_id, details in self.products.items():
        if details['quantity'] < 10:  # Threshold from requirements
            reorder_qty = details['quantity'] + 50  # Formula from requirements
            low_stock_products.append({
                'id': product_id,
                'name': details['name'],
                'current_qty': details['quantity'],
                'reorder_qty': reorder_qty
            })
    
    if not low_stock_products:
        print("No low stock items found.")
        return
    
    # Display alerts
    print("\n=== LOW STOCK ALERTS ===")
    for item in low_stock_products:
        print(f"Product ID: {item['id']}")
        print(f"Name: {item['name']}")
        print(f"Current Quantity: {item['current_qty']}")
        print(f"Recommended Reorder Quantity: {item['reorder_qty']}")
        print("-" * 40)
    
    # Save to file
    with open('low_stock_alerts.txt', 'w') as file:
        for item in low_stock_products:
            file.write(f"{item['id']},{item['name']},{item['current_qty']},{item['reorder_qty']}\n")
    
    print(f"Alerts saved to low_stock_alerts.txt")

# Add to display_menu():
print("5. Low Stock Alert")

# Add to run() method:
elif choice == '5':
    self.low_stock_alert()
```

**Key Requirements Met**:
- Threshold: quantity < 10 units
- Display format: Product ID, Name, Current Quantity, Recommended Reorder Quantity
- Reorder formula: current_quantity + 50
- File output: CSV format to "low_stock_alerts.txt"
- Menu integration: Option "5"
