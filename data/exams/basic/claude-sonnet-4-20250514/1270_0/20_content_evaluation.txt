## Passing Criteria and Scoring Rubric

### Overall Passing Threshold: 80%

**Total Points: 100**
**Minimum Passing Score: 80 points**

### Detailed Scoring Breakdown

**1. Final Inventory Calculations (35 points)**
- All 5 affected items calculated correctly (A001, A002, B001, B002, C001): 35 points
- 4 items correct: 28 points
- 3 items correct: 21 points
- 2 items correct: 14 points
- 1 item correct: 7 points
- 0 items correct: 0 points
- *Note: Items with no transactions (D001, D002, E001, E002, F001) should remain unchanged*

**2. Transaction Validation and Rejection Logic (25 points)**
- All 3 rejections identified correctly with proper reasons: 25 points
- 2 rejections correct (with reasons): 17 points
- 1 rejection correct (with reason): 8 points
- Rejections identified but reasons incorrect: 5 points
- No rejections identified correctly: 0 points

**3. Low Stock Alert Generation (10 points)**
- Correct identification of B002 and C001 only: 10 points
- One correct alert (either B002 or C001): 5 points
- Incorrect alerts or missing required alerts: 0 points

**4. Daily Summary Accuracy (10 points)**
- All 4 summary counts correct: 10 points
- 3 out of 4 counts correct: 7 points
- 2 out of 4 counts correct: 5 points
- 1 out of 4 counts correct: 2 points
- No counts correct: 0 points

**5. Equipment Integration (15 points)**
- Equipment commands correctly mapped and sequenced (10 points)
- Equipment summary calculations correct (5 points)
- Partial equipment functionality: 7-12 points
- No equipment integration: 0 points

**6. Code Quality and Execution (5 points)**
- Code executes without errors and produces correct output: 5 points
- Code executes with minor issues but produces mostly correct results: 3 points
- Code partially functional: 1 point
- Code doesn't execute or produces no meaningful output: 0 points

### Critical Success Requirements

To achieve a passing score (80+), candidates must demonstrate:

1. **Core Programming Competency**: Accurate processing of at least 80% of inventory calculations
2. **Business Logic Implementation**: Proper validation and rejection of invalid transactions
3. **Data Integration Skills**: Basic ability to work with multiple data sources
4. **System Thinking**: Understanding of how different components interact

### Acceptable Variations

- Different programming languages (Python, Java, C#, JavaScript, etc.)
- Alternative data structure approaches (lists vs. dictionaries)
- Minor variations in error message wording (as long as meaning is clear)
- Different but logically equivalent code organization
- Reasonable alternative approaches to equipment response mapping

### Automatic Failure Conditions (Below 50%)

- Non-executable code that produces no output
- Missing critical JSON fields (final_inventory, rejected_transactions)
- Major calculation errors affecting majority of inventory items
- Complete absence of transaction validation
- Incorrect data types in JSON output

### Grade Boundaries

- **90-100 points**: Excellent - Professional level competency
- **80-89 points**: Good - **PASSING** - Entry-level competency demonstrated
- **70-79 points**: Satisfactory - **NOT PASSING** - Some skills present but insufficient
- **60-69 points**: Needs Improvement - **NOT PASSING** - Basic understanding lacking
- **Below 60 points**: Unsatisfactory - **NOT PASSING** - Fundamental skills missing

This evaluation framework ensures that candidates who pass can perform essential computer programming tasks in a professional environment while providing clear, objective assessment criteria.
